{# Text inputs that follow the content-language switch. Every box here binds :value/@input rather than x-model, because x-model needs one fixed source of truth and the whole point of this editor is that the source swaps when the creator changes language. `tGet`/`tSet` (contentI18n in static/js/main.js) decide which side is being written. The placeholder is the original text. That does two jobs at once: it says what the box is FOR, and it shows exactly what a visitor will read if it is left empty — so the fallback is visible rather than a thing to discover later. #} {% macro t_hint(path) %} {# Only while translating, and only when there is an original worth copying. Useful more often than it sounds: proper nouns, prices written into a sentence, and names that are the same in both languages. #} {% endmacro %} {% macro t_input(path, id, placeholder, classes='input-field', maxlength=None) %} {{ t_hint(path) }} {% endmacro %} {% macro t_textarea(path, id, placeholder, rows=3, classes='input-field') %} {{ t_hint(path) }} {% endmacro %} {# For rows inside a repeating collection, where the path is built at runtime from the row's id. `expr` is a JS expression evaluating to the full path. #} {% macro t_row_input(expr, placeholder, classes='input-field', maxlength=None) %} {% endmacro %}
